Part A — The given circuit: start with H and X, then our block "C"¶

A1. What the lecturer asked for¶

The lecturer explained the task like this: start with H on qubit 0 and X on qubit 1, then add block C = at least 2–3 more gates of our choice, including a controlled gate such as CNOT, measure both qubits, and explain why each gate was chosen, what happens to the qubits, whether entanglement is created and what the results mean.

A2. Our block C: "make a Bell pair, flip its phase, then read it in the Bell basis"¶

q0: ──H────■────Z────■────H───M
           │         │
q1: ──X────X─────────X────────M
           └──── block C ────┘

| Gate | Qubit | Why we chose it | |---|---|---| | H | q0 | (given) puts q0 into superposition $(|0\rangle+|1\rangle)/\sqrt2$ | | X | q1 | (given) flips q1 to $|1\rangle$ | | CNOT (q0→q1) | both | creates entanglement: the Bell state $|\Psi^+\rangle$ | | Z | q0 | adds a minus sign (phase) to one branch: $|\Psi^+\rangle \to |\Psi^-\rangle$ — a change no direct measurement can see | | CNOT (q0→q1) | both | first half of a Bell measurement: it undoes the entanglement | | H | q0 | second half of the Bell measurement: turns the hidden phase into a 0/1 bit | | M | both | read the two bits |

So block C has 4 gates (2 of them CNOTs). It shows the full life of an entangled pair: created → changed → measured. This is the same idea as superdense coding (Bennett & Wiesner, 1992): one local gate (Z) on one qubit changes which Bell state the pair is in.

A3. Step-by-step maths¶

We write states as $|q_0 q_1\rangle$ in this table (Qiskit prints the opposite order, $c_1c_0$).

| Step | Gate | State $|q_0 q_1\rangle$ | Entangled? | |---|---|---|---| | 0 | start | $|00\rangle$ | no | | 1 | H on q0, X on q1 | $\tfrac{1}{\sqrt2}(|0\rangle+|1\rangle)\otimes|1\rangle = \tfrac{1}{\sqrt2}(|01\rangle+|11\rangle)$ | no | | 2 | CNOT | $\tfrac{1}{\sqrt2}(|01\rangle+|10\rangle) = |\Psi^+\rangle$ | yes | | 3 | Z on q0 | $\tfrac{1}{\sqrt2}(|01\rangle-|10\rangle) = |\Psi^-\rangle$ | yes | | 4 | CNOT | $\tfrac{1}{\sqrt2}(|01\rangle-|11\rangle) = \tfrac{1}{\sqrt2}(|0\rangle-|1\rangle)\otimes|1\rangle$ | no | | 5 | H on q0 | $|1\rangle\otimes|1\rangle = |11\rangle$ | no |

Predictions (Qiskit key $c_1c_0$):

  • Run A-1, checkpoint (measure after step 3): only 01 and 10, about 50 % each — the two qubits are always opposite (entanglement correlation).
  • Run A-2, full circuit: 11 with 100 % — the Bell measurement identifies $|\Psi^-\rangle$ with certainty.
  • Run A-3, control (same circuit without Z): 10 with 100 % — so the Z gate (a pure phase) changed qubit 0's answer from 0 to 1.

def task2a_circuit(with_z=True, stop_after_z=False):
    """H, X, then block C = CNOT, Z, CNOT, H. Options build the checkpoint and the control run."""
    qc = QuantumCircuit(2, 2, name="Task2A")
    qc.h(0)                                   # given: H on qubit 0 -> superposition
    qc.x(1)                                   # given: X on qubit 1 -> |1>
    qc.barrier()                              # ---- block C starts ----
    qc.cx(0, 1)                               # C1: CNOT q0 -> q1 creates the Bell state |Psi+>
    if with_z:
        qc.z(0)                               # C2: Z on q0 adds a minus sign: |Psi+> -> |Psi->
    if not stop_after_z:
        qc.cx(0, 1)                           # C3: CNOT again un-entangles the pair (Bell measurement, part 1)
        qc.h(0)                               # C4: H turns the phase into a bit (Bell measurement, part 2)
    qc.barrier()                              # ---- block C ends ----
    qc.measure([0, 1], [0, 1])                # q0 -> c[0], q1 -> c[1]
    return qc

A5. Is entanglement really created? (Entanglement entropy after every gate)¶

A clear test: trace out q1 and compute the von Neumann entropy $S$ of q0 alone (Nielsen & Chuang, 2010). $S = 0$ means the qubits are independent; $S = 1$ bit means they are maximally entangled.

In [4]:
from qiskit.quantum_info import partial_trace, entropy
steps = [("start", []), ("H q0, X q1", [("h", 0), ("x", 1)]), ("CNOT", [("cx", 0, 1)]),
         ("Z q0", [("z", 0)]), ("CNOT", [("cx", 0, 1)]), ("H q0", [("h", 0)])]
qc_step, rows = QuantumCircuit(2), []
for name, gates in steps:
    for g in gates:                                        # add this step's gates
        getattr(qc_step, g[0])(*g[1:])
    sv = Statevector(qc_step)                              # exact state after the step
    s = entropy(partial_trace(sv, [1]), base=2)            # entropy of q0 alone (bits)
    amps = {k: complex(np.round(v, 3)) for k, v in sv.to_dict().items() if abs(v) > 1e-9}
    rows.append({"After": name, "Amplitudes (Qiskit |q1 q0>)": amps,
                 "Entanglement entropy (bits)": round(float(s), 3),
                 "Entangled?": "YES" if s > 0.5 else "no"})
ent_table = pd.DataFrame(rows)
display(ent_table)
ent_table.to_csv(RESULTS / "task2a_entanglement_steps.csv", index=False)

A8. What the measurement results mean¶

  • A-1 (checkpoint): only 01 and 10 appear, about half each. Each qubit alone is a fair coin, but the pair is always opposite. This correlation cannot come from two independent qubits, so the CNOT really created entanglement (entropy = 1 bit in A5).
  • A-2 (full circuit): every shot gives 11. The second CNOT and the H act as a Bell measurement, which tells the four Bell states apart. 11 means the pair was in $|\Psi^-\rangle$.
  • A-3 (control, no Z): every shot gives 10. The only difference from A-2 is the Z gate. Z never changes a probability directly, but it changed the phase, and the later gates turned that phase into a different bit. This shows that phase is real, physical information.

Part B — Our own circuit written in QASM: a quantum half adder¶

B1. Why this design? (Creativity with a purpose)¶

A half adder adds two bits A and B and returns SUM = A XOR B and CARRY = A AND B. In a normal computer you run it four times to see the whole truth table. Here the inputs are put into superposition, so one circuit holds all four additions at once. Each measurement then shows one complete row of the truth table, and 1000 shots show all rows with about 25 % each.

Qubit Role Gates used and why
q0 input A H (superposition), Z (phase flip — teaches that phase is invisible to a direct measurement)
q1 input B H, S (quarter-turn phase — same lesson)
q2 CARRY CCX / Toffoli (A AND B)
q3 SUM two CX gates (A XOR B)

Gates used: H, Z, S, CX, CCX (Toffoli), barrier, measure — five different gate types on four qubits.

// =====================================================================
// MSE802 Assessment 2 - Task 2 Part B : our own circuit, written in QASM
// "Quantum half adder in superposition"
// Group project: Anish Shrestha and Sandhya Tiwari
//
// Qubit roles:  q[0] = A (input)   q[1] = B (input)
//               q[2] = CARRY (A AND B)   q[3] = SUM (A XOR B)
// Idea: H gates put A and B into superposition, so ONE circuit adds
// 0+0, 0+1, 1+0 and 1+1 at the same time. Each shot shows one of them.
// =====================================================================
OPENQASM 2.0;
include "qelib1.inc";
qreg q[4];              // four qubits, all start in |0>
creg c[4];              // four classical bits for the results

h q[0];                 // A -> (|0> + |1>)/sqrt(2)
h q[1];                 // B -> (|0> + |1>)/sqrt(2)
z q[0];                 // phase flip: A becomes (|0> - |1>)/sqrt(2); probabilities do NOT change
s q[1];                 // S = quarter-turn phase on B: (|0> + i|1>)/sqrt(2); probabilities do NOT change
barrier q;              // visual separator (ignored by the hardware)

ccx q[0],q[1],q[2];     // Toffoli: CARRY flips to 1 only when A = 1 AND B = 1
cx q[0],q[3];           // SUM = SUM XOR A
cx q[1],q[3];           // SUM = SUM XOR B  ->  SUM = A XOR B
barrier q;

measure q[0] -> c[0];   // read A
measure q[1] -> c[1];   // read B
measure q[2] -> c[2];   // read CARRY
measure q[3] -> c[3];   // read SUM

B3. Translate to Quokka's gate set, then run on Quokka (1000 shots)¶

The official Quokka docs notebook lists the QASM gates the Quokka simulator understands: h, x, y, z, rx, ry, rz, cx, swap, cphase, U. Our circuit uses s and ccx (Toffoli), which are not on that list. The team helper qh.to_quokka_gates() therefore rewrites the circuit before it is sent:

  • S → RZ(π/2) (the same up to a global phase, which can never change a measurement)
  • Toffoli → the standard decomposition with 6 CNOTs, 2 H and 7 RZ(±π/4) gates (Barenco et al., 1995)

The local simulator runs exactly the same rewritten script, so both paths test what Quokka would receive.

Conclusion¶

  • Part A: after the given H and X gates, our block C (CNOT, Z, CNOT, H) created a Bell pair, changed it from $|\Psi^+\rangle$ to $|\Psi^-\rangle$ with one phase gate, and then read it with a Bell measurement. The checkpoint run showed the entanglement (always-opposite bits), the full run gave 11 every time, and the control run without Z gave 10 every time.
  • Part B: our QASM half adder evaluated all four additions in one circuit. Every recorded shot is a correct row of the adder truth table, and the four rows appear with roughly equal frequency.
  • A key lesson: phase gates (Z, S) change amplitudes but not measurement probabilities, so they only matter when a later gate makes amplitudes interfere.
